Gup Shup – Real-Time Chat Application

A modern real-time chat application built with the MERN Stack that enables users to communicate instantly through a clean and responsive interface. It includes secure authentication, persistent conversations, and a scalable backend architecture.

Real-time messaging

Secure JWT Authentication

Responsive UI for desktop and mobile
